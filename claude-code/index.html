รวมเครื่องมือ

เลือกเครื่องมือที่ต้องการ ใช้งานผ่านเบราว์เซอร์ได้ทันทีทั้งบนคอมพิวเตอร์และมือถือ ไม่ต้องติดตั้งโปรแกรม

  • แปลงรายชื่อ CSV เป็น vCard แปลงไฟล์รายชื่อ .csv จาก Excel, Google Contacts หรือ Outlook เป็นไฟล์ .vcf สำหรับนำเข้ามือถือ Android และ iPhone แปลงในเบราว์เซอร์ ไฟล์ไม่ถูกส่งขึ้นอินเทอร์เน็ต csv2vcf/
  • สแกนเอกสารเป็น PDF ถ่ายภาพหรือเลือกรูปเอกสารแล้วสร้างไฟล์ PDF พร้อมครอปอัตโนมัติ ลบเงา ปรับภาพให้คมชัด แปลงรูปเป็นข้อความ (OCR) และแปลงไฟล์ PDF เป็นรูป JPG หรือ Word doc2pdf/
  • สร้าง QR Code สร้าง QR Code จากลิงก์ ข้อความ WiFi เบอร์โทร อีเมล หรือพร้อมเพย์พร้อมจำนวนเงิน ปรับสี รูปแบบ ใส่โลโก้ และดาวน์โหลดเป็น PNG หรือ SVG ข้อมูลไม่ถูกส่งขึ้นอินเทอร์เน็ต qrcode-generator/
  • แก้ไข PDF + AI เพิ่มข้อความภาษาไทย ลายเซ็น และรูปลงไฟล์ PDF จัดเรียง หมุน ลบ รวมหน้า ตั้งรหัสผ่าน แปลงเป็นรูป และสรุป/ถามตอบเนื้อหาด้วย AI (Gemini ใช้ API Key ของคุณ) แก้ไขในเบราว์เซอร์ pdfedit/
  • ลบพื้นหลังรูปภาพ AI แยกวัตถุออกจากพื้นหลังอัตโนมัติ รองรับ JPG PNG BMP WebP HEIC SVG ICO GIF TIFF ปรับขอบ แก้ด้วยแปรง เปลี่ยนสีพื้นหลัง ดาวน์โหลด PNG โปร่งใส ประมวลผลในเครื่อง รูปไม่ถูกส่งขึ้นอินเทอร์เน็ต bg-remove/
  • ฝากไฟล์ อัปโหลดไฟล์ละไม่เกิน 100 MB ไปยัง Google Drive หรือ OneDrive ของคุณเอง (เข้าสู่ระบบด้วย Gmail/Outlook) หรือเว็บฝากไฟล์ฟรีที่ไม่ต้องสมัคร แล้วรับลิงก์แชร์ พร้อมแจ้งข้อจำกัดของแต่ละที่ file-share/
