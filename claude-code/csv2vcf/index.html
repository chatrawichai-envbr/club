csv2vcf

แปลงรายชื่อ CSV เป็น vCard

เลือกไฟล์รายชื่อ .csv แล้วดาวน์โหลดไฟล์ .vcf ไปนำเข้ามือถือ Android, iPhone, Google Contacts หรือ Outlook ได้ทันที

ตัวเลือกเพิ่มเติม

แปลงสำเร็จ

ดาวน์โหลดไฟล์ .vcf

ตัวอย่างรายชื่อ

      นำไฟล์ .vcf เข้ามือถือ

      • Android: เปิดแอปรายชื่อ (Contacts) → เมนู → นำเข้า → เลือกไฟล์ .vcf
      • iPhone: ส่งไฟล์ .vcf ให้ตัวเองทางอีเมลหรือ AirDrop แล้วแตะเปิด → เพิ่มรายชื่อทั้งหมด
      • Google Contacts: เข้า contacts.google.com → นำเข้า → เลือกไฟล์ .vcf

      ไฟล์ CSV ควรเป็นแบบไหน

      แถวแรกต้องเป็นหัวตาราง ใช้ชื่อคอลัมน์ภาษาไทยหรืออังกฤษก็ได้ เช่น ชื่อ นามสกุล เบอร์โทร มือถือ อีเมล บริษัท ที่อยู่ จังหวัด วันเกิด หรือ Name Phone Email ดาวน์โหลดไฟล์ตัวอย่าง

      เคล็ดลับ: ใน Excel ให้ตั้งคอลัมน์เบอร์โทรเป็น “ข้อความ” ก่อนบันทึกเป็น “CSV UTF-8” ไม่เช่นนั้นเลข 0 ข้างหน้าจะหายไป

      แปลงไฟล์ในเบราว์เซอร์ของคุณทั้งหมด ไฟล์รายชื่อไม่ถูกส่งขึ้นอินเทอร์เน็ต
