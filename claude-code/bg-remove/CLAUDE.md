# แนวทางการทำงานในโฟลเดอร์ bg-remove/

ใช้กฎของทั้ง repo ใน `../CLAUDE.md` ด้วย (ตอบภาษาไทย ตรวจบั๊กและช่องโหว่ push `main` เท่านั้น) กฎเฉพาะของระบบนี้:

- รันเทสต์ในโฟลเดอร์นี้ให้ผ่านก่อน commit: `python3 -m unittest discover -s tests -v`
  (รัน `js/core.js` ด้วย Node.js ผ่าน `tests/harness.js` ถ้าไม่มี Node.js จะข้าม)
- ห้ามโหลดไฟล์จากเว็บอื่น (CDN, Hugging Face, Google Fonts) ทุกไลบรารีและโมเดลอยู่ใน `vendor/`
  CSP ของหน้าอนุญาตเฉพาะ `'self'` — รูปของผู้ใช้ต้องไม่ถูกส่งออกนอกเครื่อง
- ตรวจชนิดรูปจากเนื้อไฟล์ด้วย `BgCore.detectFormat` เสมอ (ไม่เชื่อชื่อ/นามสกุล/ชนิดที่เบราว์เซอร์บอก)
  SVG แสดงผ่าน `<img>` เท่านั้น (สคริปต์ใน SVG ไม่ทำงาน) ห้ามใส่ SVG ของผู้ใช้ลงหน้าเว็บตรง ๆ
- ข้อความจากไฟล์/ผู้ใช้ใส่หน้าเว็บด้วย `textContent` เท่านั้น (ห้าม `innerHTML`)
- ช่องเลือกไฟล์ในหน้าใช้ `accept="image/*"` เท่านั้น (Firefox บน Android ล่มเมื่อมีนามสกุล)
  `js/app.js` เพิ่มนามสกุลให้เฉพาะเบราว์เซอร์ที่ไม่ใช่ Android
- งานหนัก (โมเดล AI, ถอดรหัส HEIC/TIFF) ทำใน Web Worker เท่านั้น และต้องมีเพดานขนาดภาพ (พิกเซล) ก่อนถอดรหัส
- ไลบรารีและโมเดลใน `vendor/` ห้ามแก้ด้วยมือ ถ้าอัปเดตต้องแก้ `SHA256SUMS` และขนาดไฟล์ใน `MODELS` ของ `js/core.js`
  ไฟล์เดียวต้องไม่เกิน 50 MB (GitHub เตือน/ปฏิเสธไฟล์ใหญ่)
