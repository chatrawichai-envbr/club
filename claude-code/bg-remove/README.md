# ลบพื้นหลังรูปภาพ (bg-remove/)

เปิดใช้งาน: <https://envburiramclub.github.io/claude-code/bg-remove/>

AI แยกวัตถุออกจากพื้นหลังให้อัตโนมัติ ประมวลผลในเบราว์เซอร์ รูปไม่ถูกส่งขึ้นอินเทอร์เน็ต
ไลบรารีและโมเดลทั้งหมดเก็บไว้ในเว็บนี้ ไม่โหลดจาก CDN หรือเว็บอื่น

- **ไฟล์ที่รองรับ:** JPG/JPEG, JFIF, PNG, BMP, WebP, HEIC/HEIF, SVG, ICO, GIF (เฟรมแรก) และ TIFF
  - ตรวจชนิดจากเนื้อไฟล์ ไม่ใช่จากนามสกุล
  - รูปที่โปร่งใสอยู่แล้วยังโปร่งใสเหมือนเดิม
- **เลือกรูป:** กดเลือก ลากมาวาง หรือวางจากคลิปบอร์ด (Ctrl+V)
- **คุณภาพ:**
  - **ละเอียด (IS-Net):** ขอบคม แยกวัตถุซับซ้อนได้ดี ดาวน์โหลดโมเดลครั้งแรก 44 MB ใช้หน่วยความจำราว 1.2 GB
  - **เร็ว (U²-Netp):** ดาวน์โหลด 4.5 MB เหมาะกับมือถือ
  - มือถือเริ่มที่โหมดเร็ว ถ้าโหมดละเอียดทำงานไม่สำเร็จ ระบบลองโหมดเร็วให้อัตโนมัติ
- **ปรับแต่งผล:**
  - ความคมของขอบ
  - แปรงลบ/คืนพื้นหลังเฉพาะจุด (ย้อนกลับได้ หรือกด Ctrl+Z)
  - กดค้างเพื่อเทียบกับต้นฉบับ
  - เปลี่ยนสีพื้นหลัง
- **ดาวน์โหลด:** PNG/WebP (โปร่งใส) หรือ JPG ตัดพื้นที่ว่างรอบวัตถุได้
- **ขนาดภาพ:** ประมวลผลไม่เกิน 16.7 ล้านพิกเซล (มือถือ 12 ล้าน) ภาพที่ใหญ่กว่านี้ถูกย่อก่อน ไฟล์ต้องไม่เกิน 60 MB
- **localStorage:** จำเฉพาะโหมดคุณภาพที่เลือก (key `bg-remove:model`)

## ไฟล์

| ไฟล์ | หน้าที่ |
| --- | --- |
| `index.html`, `css/app.css`, `favicon.svg` | หน้าเว็บ (CSP อนุญาตเฉพาะไฟล์จากเว็บนี้ ไม่มีสคริปต์/สไตล์ในหน้า) |
| `js/app.js` | ควบคุมหน้าเว็บ: เปิดรูป, ส่งให้ worker, สร้างผลลัพธ์, แปรง, ดาวน์โหลด |
| `js/core.js` | ฟังก์ชันล้วน (ชนิดไฟล์, ขนาด SVG, อินพุต/เอาต์พุตของโมเดล, ย่อภาพ, ชื่อไฟล์) ใช้ทั้งหน้าเว็บ worker และเทสต์ |
| `js/ai-worker.js` | Web Worker รันโมเดลด้วย ONNX Runtime Web (WebAssembly) |
| `js/decode-worker.js` | Web Worker ถอดรหัส HEIC/HEIF (libheif) และ TIFF (UTIF.js) ที่เบราว์เซอร์เปิดเองไม่ได้ |
| `vendor/onnxruntime/` | ONNX Runtime Web 1.30.0 (MIT) |
| `vendor/models/isnet/` | IS-Net (DIS) quantize 8 บิต — จาก `@imgly/background-removal-data` ซึ่งเผยแพร่แบบ AGPL-3.0 (ดู `SOURCE.txt`, `LICENSE.md`) |
| `vendor/models/u2netp/` | U²-Netp (Apache-2.0) |
| `vendor/libheif/` | libheif-js (LGPL-3.0) ชุดเดียวกับ doc2pdf |
| `vendor/utif/` | UTIF.js (MIT) และ pako inflate (MIT/Zlib) |
| `tests/test_bgremove.py`, `tests/harness.js` | เทสต์ฟังก์ชันใน `js/core.js` (Node.js) และตรวจความปลอดภัยของหน้าเว็บ |

ทุกโฟลเดอร์ใน `vendor/` มี `SHA256SUMS` (เทสต์ของหน้าหลักตรวจว่าไฟล์ไม่ถูกแก้)

## เทสต์

python3 -m unittest discover -s tests -v
