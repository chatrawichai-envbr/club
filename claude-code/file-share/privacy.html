นโยบายความเป็นส่วนตัว

ระบบฝากไฟล์ (envburiramclub.github.io/claude-code/file-share/) — ปรับปรุงล่าสุด 30 กันยายน 2569

ระบบนี้ทำงานอย่างไร

ระบบฝากไฟล์เป็นหน้าเว็บที่ทำงานในเบราว์เซอร์ของคุณทั้งหมด ไม่มีเซิร์ฟเวอร์ของตัวเอง ไฟล์ส่งตรงจากเครื่องของคุณไปยังที่ฝากที่คุณเลือก (Google Drive, Microsoft OneDrive หรือเว็บฝากไฟล์ฟรี) ผู้ดูแลระบบจึงไม่เห็นและไม่ได้รับไฟล์ รหัสผ่าน หรือข้อมูลบัญชีของคุณ

ข้อมูลที่ระบบเข้าถึงและใช้ทำอะไร

Google Drive (สิทธิ์ drive.file)

  • สร้างโฟลเดอร์ "ระบบฝากไฟล์" และอัปโหลดไฟล์ที่คุณเลือกลงในโฟลเดอร์นั้น
  • เปิดลิงก์แชร์แบบ "ทุกคนที่มีลิงก์" เฉพาะเมื่อคุณติ๊กเลือก
  • แสดงรายการและย้ายไปถังขยะ เฉพาะไฟล์ที่อัปโหลดผ่านระบบนี้ — ระบบไม่เห็นไฟล์อื่นใน Google Drive ของคุณ
  • อ่านชื่อ อีเมล และพื้นที่ที่ใช้ไป เพื่อแสดงบนหน้าเว็บเท่านั้น

Microsoft OneDrive (สิทธิ์ Files.ReadWrite และ User.Read)

  • อัปโหลดไฟล์ที่คุณเลือกลงในโฟลเดอร์ของแอป (OneDrive/Apps) และสร้างลิงก์แชร์เฉพาะเมื่อคุณติ๊กเลือก
  • แสดงรายการและลบไฟล์ในโฟลเดอร์ของแอปเท่านั้น
  • อ่านชื่อ อีเมล และพื้นที่ที่ใช้ไป เพื่อแสดงบนหน้าเว็บเท่านั้น

เว็บฝากไฟล์ฟรี (tmpfiles.org, Gofile.io)

  • ส่งไฟล์และชื่อไฟล์ไปยังบริการที่คุณเลือก ไฟล์เป็นสาธารณะและอยู่ภายใต้นโยบายของบริการนั้น

การใช้ข้อมูลจาก Google (Limited Use)

การใช้และการส่งต่อข้อมูลที่ได้รับจาก Google API ของระบบนี้เป็นไปตาม Google API Services User Data Policy รวมถึงข้อกำหนด Limited Use:

  • ใช้ข้อมูลเฉพาะเพื่อทำงานที่คุณสั่งบนหน้าเว็บ (อัปโหลด แชร์ แสดงรายการ และลบไฟล์)
  • ไม่ส่งต่อ ขาย หรือเปิดเผยข้อมูลให้บุคคลอื่น ไม่ใช้เพื่อโฆษณา และไม่ใช้ฝึกโมเดล AI
  • ไม่มีคนอ่านข้อมูลของคุณ

The use and transfer of information received from Google APIs by this app adheres to the Google API Services User Data Policy, including the Limited Use requirements.

สิ่งที่เก็บในเครื่องของคุณ

  • โทเคนการเข้าสู่ระบบอยู่ในหน่วยความจำของหน้าเว็บเท่านั้น หายไปเมื่อปิดหน้า (หมดอายุภายใน 1 ชั่วโมง)
  • localStorage เก็บเฉพาะที่ฝากไฟล์ที่เลือกล่าสุด (key file-share:provider)
  • sessionStorage เก็บค่าสุ่มสำหรับตรวจความถูกต้องของการเข้าสู่ระบบชั่วคราว (key file-share:auth) และลบทันทีที่กลับมาจากหน้าเข้าสู่ระบบ
  • ไม่มีคุกกี้ ไม่มีระบบวิเคราะห์การใช้งาน และไม่มีโฆษณา

การยกเลิกสิทธิ์และการลบข้อมูล

  • กด "ออกจากระบบ" บนหน้าฝากไฟล์ (Google: ยกเลิกโทเคนทันที)
  • ยกเลิกสิทธิ์ถาวร: Google ที่ myaccount.google.com/permissions และ Microsoft ที่ account.live.com/consent/Manage
  • ไฟล์อยู่ใน Google Drive/OneDrive ของคุณเอง ลบได้จากหน้าฝากไฟล์หรือจาก Drive/OneDrive โดยตรง ไฟล์บนเว็บฝากไฟล์ฟรีถูกลบตามนโยบายของแต่ละบริการ
