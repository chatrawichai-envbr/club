# แก้ไข PDF + AI (pdfedit/)

เปิดใช้งาน: <https://envburiramclub.github.io/claude-code/pdfedit/>

แก้ไขไฟล์ PDF ในเบราว์เซอร์ ไฟล์ไม่ถูกส่งขึ้นอินเทอร์เน็ต ยกเว้นเมื่อใช้ฟีเจอร์ AI

- **เพิ่มองค์ประกอบ:** ข้อความภาษาไทย (ฟอนต์ TH Sarabun New ฝังในไฟล์) วาดลายเซ็น และรูปภาพ ลากย้าย ย่อ/ขยาย แก้ไข และลบได้
- **จัดการหน้า:** จัดเรียงหน้า หมุนหน้า ลบหน้า และรวมไฟล์ PDF อีกไฟล์เข้ามา
  องค์ประกอบที่เพิ่มไว้ย้ายตามหน้า และอยู่ตำแหน่งเดิมบนเนื้อหาแม้หมุนหน้า
- **เครื่องมือเสริม:**
  - ตั้งรหัสผ่านไฟล์ (AES-256)
  - รวมเลเยอร์เป็นรูป (Flatten)
  - แปลงทุกหน้าเป็นรูป PNG ในไฟล์ ZIP
  - เปิดไฟล์ที่มีรหัสผ่านได้ (ถามรหัส) ไฟล์ที่ส่งออกใช้รหัสผ่านเดิมจนกว่าจะเปลี่ยน
- **AI (Google Gemini):** สรุปเนื้อหา และถาม-ตอบจากเอกสาร (สูงสุด 10 หน้าแรก)
  - ต้องใช้ API Key ของผู้ใช้เอง (<https://aistudio.google.com/app/apikey>)
  - ระบบจำ key ไว้ในหน่วยความจำจนกว่าจะปิดหน้า ไม่บันทึกลงเครื่อง
  - ถามยืนยันก่อนส่งข้อความในไฟล์ให้ Google
- **ธีม:** เลือกสีธีมได้ ระบบจำไว้ใน `localStorage` (key `pdfedit:theme` เก็บเฉพาะสี)

## ไฟล์

| ไฟล์ | หน้าที่ |
| --- | --- |
| `index.html`, `favicon.svg` | หน้าเว็บ (CSP ไม่อนุญาตสคริปต์/สไตล์ในหน้า ส่งข้อมูลออกได้เฉพาะ Gemini API) |
| `js/app.js` | ควบคุมหน้าเว็บ: เปิดไฟล์ แสดงหน้า องค์ประกอบ จัดการหน้า ส่งออก AI ตั้งค่า |
| `js/pdf-core.js` | ฟังก์ชันล้วน (ตรวจชนิดไฟล์, EXIF, ชื่อไฟล์, พิกัดเมื่อหมุนหน้า, แปลงคำตอบ AI) เทสต์ได้ใน Node |
| `js/dialog.js` | หน้าต่างแจ้งเตือน/ยืนยัน/กรอกข้อมูล สร้างด้วย DOM (แทน SweetAlert2) |
| `css/app.css` | สไตล์เฉพาะของหน้านี้ และ `@font-face` ของไอคอนกับฟอนต์ไทย |
| `css/tailwind.css` | คลาส Tailwind ที่หน้านี้ใช้ (สร้างจากคำสั่งด้านล่าง ห้ามแก้ด้วยมือ) |
| `vendor/pdfjs/` | PDF.js 6.3.289 (Apache-2.0) แสดงหน้า PDF และดึงข้อความ |
| `vendor/pdf-lib/`, `vendor/fontkit/` | @cantoo/pdf-lib 2.11.1 และ @pdf-lib/fontkit 1.1.1 (MIT) แก้ไข/เข้ารหัสไฟล์ ฝังฟอนต์ไทย |
| `vendor/jszip/` | JSZip 3.10.2 (MIT) รวมรูปเป็นไฟล์ ZIP |
| `vendor/fontawesome/` | ไอคอน Font Awesome Free 6.7.2 ชุด solid |
| `vendor/fonts/` | TH Sarabun New (GPL-2.0+ พร้อมข้อยกเว้นให้ฝังในเอกสาร — ดู `LICENSE`) |
| `tests/test_pdfedit.py`, `tests/harness.js` | เทสต์ฟังก์ชันใน `js/pdf-core.js` (Node.js) และตรวจความปลอดภัยของหน้าเว็บ |

ไลบรารีใน `vendor/` โหลดเมื่อจำเป็นเท่านั้น (PDF.js ตอนเปิดไฟล์, fontkit และฟอนต์ตอนส่งออกไฟล์ที่มีข้อความ, JSZip ตอนแปลงเป็นรูป)

## สร้าง css/tailwind.css ใหม่

เมื่อเพิ่มหรือเปลี่ยนคลาส Tailwind ใน `index.html` หรือ `js/*.js` ให้รันที่โฟลเดอร์นี้:

```bash
npx tailwindcss@3.4.17 --content "./index.html,./js/*.js" -o css/tailwind.css --minify
```

## เทสต์

```bash
python3 -m unittest discover -s tests -v
```

บางเทสต์ต้องมี Node.js ถ้าไม่มีจะข้าม
