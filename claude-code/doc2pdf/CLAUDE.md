# แนวทางการทำงานในโฟลเดอร์ doc2pdf/

ใช้กฎของทั้ง repo ใน `../CLAUDE.md` ด้วย (ตอบภาษาไทย ตรวจบั๊กและช่องโหว่ push `main` เท่านั้น) กฎเฉพาะของระบบนี้:

- รันเทสต์ในโฟลเดอร์นี้ให้ผ่านก่อน commit: `python3 -m unittest discover -s tests -v`
  (รันโค้ดใน `js/` ด้วย Node.js ผ่าน `tests/harness.js` ถ้าไม่มี Node.js จะข้าม)
- โค้ดใน `js/` ใช้ร่วมกับเวอร์ชัน Google Apps Script และแอป Android ผ่าน `window.AppPlatform` (`js/boot.js`)
  หาไฟล์ขณะทำงานผ่าน `AppPlatform.resolve`/`loadScript` เท่านั้น และห้ามใส่ลิงก์ `../index.html` ในหน้าแอป
- ข้อมูลจากไฟล์ของผู้ใช้ (รูป, PDF, ข้อความ OCR) ไม่น่าเชื่อถือ: ใส่หน้าเว็บด้วย `textContent` เท่านั้น
  ทุกลูปและการคลายการบีบอัดต้องมีเพดาน ห้ามใช้ regex แบบ `/[ \t]+$/` กับข้อความยาว (ใช้ลูปไล่จากท้ายสตริง)
- ไลบรารีใน `vendor/` ห้ามแก้ด้วยมือ ถ้าอัปเดตต้องแก้ `SHA256SUMS` ของโฟลเดอร์นั้นด้วย
- ห้ามโหลดไฟล์จากเว็บอื่น (CDN, Google Fonts) ใช้ไฟล์ใน `vendor/` และฟอนต์ที่มีในเครื่อง
  CSP อนุญาตเฉพาะ `'self'` (`tests/test_static.py` ตรวจ)
